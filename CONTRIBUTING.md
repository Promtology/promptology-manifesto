# Współtworzenie Manifestu Promptologii 🇵🇱

## Wprowadzenie
Manifest Promptologii to projekt otwarty.  
Łączy badania, filozofię, sztukę i naukę o języku.  
Nie jest kodem — jest **żywym tekstem**, który ewoluuje wraz z nowymi interpretacjami.

## Jak możesz pomóc
- Dodawaj nowe rozdziały, komentarze i interpretacje.  
- Rozwijaj teorię BRAMA — proponuj nowe warstwy, analogie lub pojęcia.  
- Uzupełniaj przypisy, ilustracje, definicje, diagramy.  
- Twórz eksperymenty językowe (promptologiczne) i opisuj ich wyniki.

## Jak zgłaszać zmiany
1. Stwórz **fork** repozytorium.  
2. Dodaj swoje poprawki lub propozycje w nowym pliku lub sekcji.  
3. Otwórz **Pull Request**, opisując *dlaczego* zmiana jest ważna.  
4. Nie musisz być naukowcem — wystarczy, że rozumiesz, czym jest sens.

## Styl i ton
- Język: polski lub angielski.  
- Styl: jasny, precyzyjny, ale z zachowaniem poetyki manifestu.  
- Używaj LaTeX do wzorów i symboli matematycznych.  
- Cytaty i odniesienia umieszczaj w formacie Markdown.

# Contributing to the Manifest of Promptology 🇬🇧

## Introduction
The Manifest of Promptology is an open project.  
It unites research, philosophy, art, and the science of language.  
It is not code — it is a **living text** evolving through interpretation.

## How to Contribute
- Add new chapters, commentary, or interpretations.  
- Expand the BRAMA framework — propose new layers, analogies, or definitions.  
- Enrich notes, references, and visual diagrams.  
- Create promptological experiments and describe their outcomes.

## Submitting Changes
1. **Fork** the repository.  
2. Add your contributions in a new file or section.  
3. Open a **Pull Request**, explaining *why* your change matters.  
4. You don’t need to be a scientist — only to understand meaning.

## Style & Tone
- Language: Polish or English.  
- Style: clear, precise, yet poetic in form.  
- Use LaTeX for equations and notation.  
- Cite and reference in Markdown format.

## Guiding Principle
> Thought evolves through relation.  
> The Manifest grows through interpretation.

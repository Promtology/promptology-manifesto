# Polityka bezpieczeństwa / Security Policy

---

## 🇵🇱 Wersje wspierane

Manifest Promptologii nie jest projektem programistycznym w klasycznym sensie,  
ale **żywym systemem tekstów, idei i relacji informacyjnych**.  
Bezpieczeństwo odnosi się tu nie do kodu, lecz do *integralności znaczenia*.

Poniższa tabela informuje, które gałęzie i wersje są aktywnie utrzymywane —  
czyli regularnie przeglądane i chronione przed manipulacją treści lub kontekstu.

| Wersja / Gałąź | Wspierana |
| --------------- | ---------- |
| main (aktualna) | ✅ |
| archived        | ⚠️ tylko do wglądu |
| experimental    | ⚠️ częściowo |
| forks           | zależnie od autora |

---

## 🇬🇧 Supported Versions

The Manifest of Promptology is not software, but a **living system of texts, ideas, and informational relations**.  
Security here refers to the *integrity of meaning*, not to code or exploits.

The table below indicates which branches or versions are actively maintained —  
i.e. monitored for contextual accuracy and protected from semantic corruption.

| Version / Branch | Supported |
| ----------------- | ---------- |
| main (current)    | ✅ |
| archived          | ⚠️ view-only |
| experimental      | ⚠️ partial |
| forks             | depends on author |

---

## 🇵🇱 Zgłaszanie naruszeń

Jeśli zauważysz:
- manipulację treścią,  
- zniekształcenie cytatu lub sensu,  
- nieautoryzowaną zmianę w tekście,  

skontaktuj się z zespołem BRAMY:  
📧 **security@promptologia.org**

Zgłoszenia analizujemy w ciągu 48 godzin.  
Ważne przypadki (np. naruszenie integralności sensu, błędne przypisy, fałszywe interpretacje) rozpatrujemy priorytetowo.  

---

## 🇬🇧 Reporting a Vulnerability

If you notice:
- manipulation of content,  
- distortion of citations or meaning,  
- unauthorized modifications to text,  

please contact the BRAMA team:  
📧 **security@promptologia.org**

Reports are reviewed within 48 hours.  
Cases that compromise the *semantic or ethical integrity* of the Manifest are treated as high priority.
